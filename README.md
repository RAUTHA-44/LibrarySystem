# Library System
A library system showing use of for,while,do-while loops and tenary statement.
The system allows a user to:
-View available books
-Enter number of borrowing days
-Choose book to borrow
-Check for borrowing limit whether within or exceeded
##Java concepts used are
for loop-to display available books
while loop-validate book selection of user
do-while loop-allow user borrow another book
ternary statement-check borrowing time
